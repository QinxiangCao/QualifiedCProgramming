# P1012 [NOIP 1998 Senior] Concatenating Numbers

## 题目描述

Given $n$ positive integers $a_1 \dots a_n$, arrange them in a row, concatenating adjacent numbers end to end, to form the largest possible integer.

## 输入格式

The first line contains an integer $n$, the number of integers.

The second line contains $n$ integers $a_i$, the given integers.

## 输出格式

Output a positive integer, the largest possible integer.

## 输入输出样例 #1

### 输入 #1

```
3
13 312 343

```

### 输出 #1

```
34331213

```

## 输入输出样例 #2

### 输入 #2

```
4
7 13 4 246
```

### 输出 #2

```
7424613
```

## 说明/提示

Constraints: For all test points, $1 \leq n \leq 20$, $1 \leq a_i \leq 10^9$.
