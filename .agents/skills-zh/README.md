# Skills ZH Mirror

本目录是 `.agents/skills` active contract 的同步中文镜像，用于中文 skill discovery 展示，不是独立流程源。

语义 source of truth 仍是 `.agents/skills`。中文文档与主 skills 保持一致，脚本和非文档资产逐字节复制。后续修改必须同步 main-root annotation 流程、唯一持续 annotation agent、`formal_case_lib` / `group_worker_lib` / `proving_merged_lib`、directory-based groups、compact reports、controller tooling 与 final-check。
